# Moldura dos slots

Arte gerada com a ferramenta integrada de imagens e copiada para moldura_slot_v2.png. Recurso no projeto: spr_slot_moldura_v2. Centro transparente verificado (alfa zero).

Aplicação: Draw dos objetos obj_slot_batalha, obj_slot_construcao, obj_slot_terreno e obj_slot_recurso. O sprite original e seus limites continuam nos objetos para preservar posicionamento e colisões. O novo desenho é ajustado às dimensões originais, com opacidade 0.72 vazio e 0.35 ocupado.

Prompt usado:
Create a production-ready single 2D game UI sprite: empty card placement slot frame for a dark fantasy tabletop card game. Portrait aspect ratio 3:4, perfectly front-facing orthographic, no perspective. One thin restrained rectangular frame of aged dark bronze and blackened iron, fine engraved wear, small elegant angular reinforced corners, subtle warm antique-gold edge highlights. Frame occupies nearly the whole canvas with only small transparent padding. Very large completely transparent empty center (at least 85 percent of width and height inside frame), genuinely transparent exterior as well. No card, no paper background, no table, no text, no letters, no symbols in the center, no glow, no particles, no cast shadow beyond small frame bevel. Tasteful premium dark medieval UI, subdued not flashy. Balanced symmetrical border, clearly readable at small game size, medium clean details rather than tiny noisy filigree. Output just the isolated frame sprite.
